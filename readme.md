## Pertemuan 4 — Design token halaman profil

- Berkas gaya yang akan dibuat: tokens.css, base.css, layout.css, komponen.css, tema.css
- Warna utama: #BE185D (pink), dipilih karena sesuai dengan tema halaman Plan Libur Semester.

### Token yang saya tetapkan

| Token | Nilai | Untuk apa |
|---|---|---|
| --color-primary | #BE185D | Tombol, tautan, penanda |
| --color-fg | #1F1720 | Warna teks utama |
| --color-bg | #FFF5F7 | Latar halaman |
| --radius-md | 0.5rem | Sudut tombol dan kartu |
| --space-4 | 1rem | Jarak antar elemen |

Kriteria selesai: mengubah --color-primary di satu baris harus mengubah warna tombol, tautan, dan penanda.
